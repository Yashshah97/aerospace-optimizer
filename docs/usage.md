# Usage

```python
import aerospace_optimizer
```

Each module is self-contained; see docstrings for the API:

- `aerospace_optimizer.optimizer` — Main optimizer class implementing search strategies
- `aerospace_optimizer.grid_optimizer` — Grid-based optimization strategy implementation
- `aerospace_optimizer.random_optimizer` — Random search optimization strategy implementation
- `aerospace_optimizer.simulated_annealing` — Simulated annealing optimization strategy implementation
- `aerospace_optimizer.parameter` — Data structure and methods for parameter handling (e.g. bounds, constraints)
- `aerospace_optimizer.test_optimizer` — Unit tests for optimizer classes
